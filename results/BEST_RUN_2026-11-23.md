# Best recipe, reproduced 2026-11-23

Command

```bash
python train_qat.py --preset best --steps 600 --batch-size 4 --seq-len 128 \
  --max-val-chunks 40 --device cpu --output-dir runs/best-full-scale-grad
```

Hardware: CPU only.

This run includes the scale-gradient fix from `docs/SCALE_GRADIENT_FIX.md`.
Earlier 21.78 and 21.88 runs trained weights but not the scales.
